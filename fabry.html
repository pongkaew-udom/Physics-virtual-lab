คู่มือการทำปฏิบัติการฟิสิกส์ขั้นสูง

การแทรกสอดของแสงผ่านเครื่องแทรกสอดแบบฟาบรี-เพโรต์
(Fabry-Pérot Interferometer)

1. ชื่อเรื่อง

การศึกษาการแทรกสอดของลำแสงหลายลำรังสี (Multiple-Beam Interference) เพื่อหาความยาวคลื่นแฝงของแหล่งกำเนิดแสงเลเซอร์และวิเคราะห์ความละเอียดของริ้วรอยแทรกสอดผ่านเครื่อง Fabry-Pérot Interferometer

2. อุปกรณ์การทดลอง (เสมือนจริง)

  • 1. แหล่งกำเนิดแสงเลเซอร์ (Laser Source): สำหรับจ่ายแสงความยาวคลื่นเดี่ยวและมีความสอดคล้องสูง (Coherent Light) ประกอบด้วยตัวเลือก 3 ชนิด:
    • เลเซอร์ฮีเลียม-นีออน (He-Ne Laser, แสงสีแดง, λtrue = 632.8 nm)
    • เลเซอร์ไดโอด (Diode Laser, แสงสีเขียว, λtrue = 532.0 nm)
    • เลเซอร์ไดโอด (Diode Laser, แสงสีม่วง/น้ำเงิน, λtrue = 405.0 nm)
  • 2. ระบบเลนส์ขยายและจัดลำแสง (Beam Expander & Collimating Lens): สำหรับเปลี่ยนลำแสงเลเซอร์จุดเส้นผ่านศูนย์กลางเล็กให้แผ่ออกเป็นหน้าคลื่นทรงกลม/ทางแสงที่กว้างขึ้นเพื่อป้อนเข้าสู่ระบบกระจก
  • 3. กระจกคู่ขนานฟาบรี-เพโรต์ (Fabry-Pérot Mirrors - M1, M2): กระจกสะท้อนแสงกึ่งโปร่งแสงคู่ขนานที่มีช่องว่างอากาศหนา d กั้นกลาง
    • กระจก M1 ยึดอยู่กับที่
    • กระจก M2 สามารถขยับระยะห่างอย่างละเอียดผ่านสกรูไมโครมิเตอร์ไฟฟ้าระหว่างระยะ 2.000 mm ถึง 2.010 mm
  • 4. ระบบปรับค่าการสะท้อนแสง (Mirror Reflectivity - R): ปรับค่าสัมประสิทธิ์การสะท้อนแสงของหน้ากระจกได้ตั้งแต่ 70% ถึง 95% เพื่อควบคุมความคมชัดของริ้วแทรกสอด
  • 5. ฉากรับภาพระบบดิจิทัล (Fringe Pattern View Screen): ฉากสำหรับรับริ้วรอยแทรกสอดวงแหวนศูนย์กลางร่วม (Concentric Rings) ควบคู่เป้าเล็งกึ่งกลาง (Crosshair) เพื่อใช้นับวงแหวนที่ผุดขึ้นหรือยุบลง

3. ทฤษฎี

เครื่องแทรกสอดแบบฟาบรี-เพโรต์ (Fabry-Pérot Interferometer) อาศัยหลักการ แทรกสอดจากการสะท้อนกลับไปมาหลายครั้ง (Multiple-Beam Interference) ระหว่างผิวกระจกสะท้อนสูงสองแผ่นที่วางขนานกันอย่างสมบูรณ์ เมื่อแสงเลเซอร์จากแหล่งกำเนิดผ่านกระจกแผ่นแรก (M1) เข้าสู่ช่องว่างอากาศหนา d แสงจะสะท้อนสะสมอยู่ภายในและทะลุผ่านกระจกแผ่นที่สอง (M2) ออกมาเป็นลำแสงคู่ขนานจำนวนมากที่มีความต่างเฟสคงที่

ความต่างเส้นทางเดินแสง (Optical Path Difference: Δ) ระหว่างลำแสงที่ทะลุผ่านออกมาแต่ละลำที่มุมตกกระทบ θ ภายในช่องอากาศ มีค่าเท่ากับ:

Δ = 2d cosθ

เงื่อนไขที่ทำให้เกิด ริ้วสว่าง (Bright Fringes) หรือวงแหวนสว่างบนฉากรับภาพ เกิดขึ้นเมื่อความต่างเส้นทางเดินแสงเป็นจำนวนเต็มเท่าของความยาวคลื่น (mλ):

2d cosθ = mλ      (m = 1, 2, 3, &dots;)

ที่จุดศูนย์กลางของเป้าเล็ง (θ = 0 ดังนั้น cosθ = 1) สมการจะลดรูปเหลือ:

2d = mλ

หากเรากำหนดระยะห่างกระจกเริ่มต้นเป็น d0 แล้วทำการขยับกระจก M2 ออกไปอย่างช้าๆ จนอยู่ที่ระยะ d ใหม่ ความหนาของช่องอากาศจะเปลี่ยนไปส่งผลให้ลำดับการแทรกสอด (m) ณ จุดศูนย์กลางเปลี่ยนแปลงไป ซึ่งจะสังเกตเห็นริ้ววงแหวนสว่างผุดขยายออกจากจุดศูนย์กลางหรือยุบตัวลงไป หากเรานับจำนวนวงแหวนสว่างที่แปรเปลี่ยนไปได้ N วง ความสัมพันธ์ระหว่างระยะที่ขยับไป (Δd) และจำนวนวงแหวน N จะเป็นไปตามสมการ:

2Δd = Nλ

ดังนั้น เราจึงสามารถคำนวณหา ความยาวคลื่นจากการทดลอง (λcal) ได้จากสูตร:

λcal = (2 · Δd) / N

เมื่อ Δd = |d - d0| คือ ระยะทางที่กระจกขยับเคลื่อนที่ไป (แปลงหน่วยจาก mm เป็นนาโนเมตร nm) และ N คือ จำนวนรอบหรือจำนวนวงแหวนสว่างที่เปลี่ยนไป ณ จุดศูนย์กลางเป้าเล็ง

ปัจจัยที่มีผลต่อความคมชัด (Finesse): ความคมชัดและความแคบของแถบสว่างขึ้นอยู่กับค่าสะท้อนแสง (R) ของกระจก ตามฟังก์ชันของแอรี่ (Airy Function) โดยมีตัวประกอบความคงสภาพ (Coefficient of Finesse, F) คือ:

F = 4R / (1 - R)2

ยิ่งค่า R มีค่าสูง (90% - 95%) ริ้ววงแหวนสว่างจะยิ่งมีความคมชัดสูงและเส้นแคบลง ทำให้การจำแนกและวัดละเอียดทำได้ง่ายขึ้น

4. วิธีการทดลอง

  1. เลือกแหล่งกำเนิดแสงเลเซอร์ชนิดแรกที่ต้องการศึกษาจากเมนูเลือกระบบ (เช่น เลือกเลเซอร์ He-Ne สีแดง ค่าจริง 632.8 nm)
  2. ปรับตัวเลื่อนระยะห่างปัจจุบัน (d) ไปที่ค่าเริ่มต้นที่ต้องการ เช่น 2.000 mm จากนั้นกดปุ่ม "เซ็ตจุดเริ่มต้นอ้างอิง (d0)" เพื่อบันทึกค่าล็อกระยะเริ่มต้นอ้างอิงของระบบ
  3. ทดลองปรับค่าการสะท้อนแสงของกระจก (R) เป็น 70%, 85% และ 95% สังเกตการเปลี่ยนแปลงลักษณะความกว้างและความคมชัดของริ้ววงแหวนสว่างบนหน้าจอฉากรับภาพ (Fringe Pattern View) บันทึกผลการสังเกตเชิงคุณภาพ (จากนั้นตั้งค่า R ไว้ที่ระดับสูง เช่น 85% หรือ 95% เพื่อความแม่นยำในการทดลอง)
  4. ค่อยๆ ปรับเลื่อนสไลด์สเกลระยะห่างปัจจุบัน (d) ให้เพิ่มขึ้นทีละน้อย สังเกตริ้ววงแหวนที่ผุดขยายตัวออกมาจากจุดศูนย์กลางผ่านเป้าเล็ง (Crosshair) ให้นับจำนวนวงแหวนสว่างที่ผุดขึ้นมาอย่างตั้งใจ (N วง) เช่น ปล่อยให้ผุดขึ้นมาครบ N = 15 หรือ 20 วง แล้วหยุดเลื่อน
  5. บันทึกระยะห่างสุดท้าย (d) จากหน้าจอ ซึ่งระบบจะคำนวณค่าผลต่างระยะขยับ Δd = |d - d0| ออกมา
  6. กดปุ่ม "บันทึก&คำนวณ" ระบบจะนำค่าผลต่างระยะขยับ Δd และจำนวนรอบวงแหวน N ไปเข้าสูตรคำนวณเพื่อหาค่าความยาวคลื่นจากการทดลอง (λcal) พร้อมทั้งเปรียบเทียบหาค่าความคลาดเคลื่อนร้อยละ (Percentage Error) ลงในตารางบันทึกผล
  7. กดปุ่ม "รีเซ็ตแล็บ" จากนั้นเปลี่ยนชนิดของแหล่งกำเนิดแสงเลเซอร์เป็นตัวถัดไป (เลเซอร์สีเขียว 532.0 nm และเลเซอร์สีม่วง/น้ำเงิน 405.0 nm) แล้วทำซ้ำตามขั้นตอนข้อ 2 - 6 เพื่อเปรียบเทียบผลการทดลอง

6. ผลการทดลองและการคำนวณ

จากการทำปฏิบัติการจำลองด้วยเครื่อง Fabry-Pérot Interferometer พบว่าเมื่อเราจ่ายเลเซอร์และทำการล็อกระยะเริ่มต้นอ้างอิง d0 ไว้ การเลื่อนระยะห่างของกระจกสะท้อนส่งผลโดยตรงต่อการเปลี่ยนแปลงทางเฟสของลำแสงที่เกิดการสะท้อนกลับไปกลับมา ภาพจำลองริ้วรอยการแทรกสอด (Fringe Pattern) แสดงให้เห็นเป็นลักษณะวงแหวนสว่างสลับมืดที่มีจุดศูนย์กลางร่วมกัน

เมื่อกระจกขยับตัวออกไป แถบวงแหวนจะผุดตัวออกจากจุดตัด Crosshair กึ่งกลางอย่างเป็นจังหวะ ตัวอย่างผลการคำนวณในกรณีเลเซอร์ He-Ne แสงสีแดง (λtrue = 632.8 nm) เมื่อขยับกระจกไปเป็นระยะ Δd = 0.00475 mm หรือคิดเป็น 4,750 nm และนับรอบวงแหวนได้ N = 15 วง จะได้คำนวณตามสูตรทัศนศาสตร์:

λcal = (2 · 4750 nm) / 15 = 633.33 nm

ซึ่งให้ค่าใกล้เคียงกับความเป็นจริงอย่างมาก โดยมีค่าความคลาดเคลื่อนร้อยละต่ำเพียง 0.08% เท่านั้น และในทำนองเดียวกันกับแสงสีเขียวและม่วงที่ให้ผลสอดคล้องตามทฤษฎีควอนตัมและทัศนศาสตร์เชิงกายภาพอย่างแม่นยำ

7. สรุปผลการทดลอง

การทดลองวิเคราะห์ด้วยเครื่อง Fabry-Pérot Interferometer ประสบความสำเร็จในการใช้วิเคราะห์หาค่าความยาวคลื่นแฝงของแหล่งกำเนิดแสงเลเซอร์ชนิดต่างๆ ได้อย่างมีประสิทธิภาพ ผลการทดลองชี้ให้เห็นว่า ผลต่างการขยับระยะห่างของกระจกสะท้อน (Δd) แปรผันตรงเชิงเส้นกับจำนวนวงแหวนสว่าง (N) ที่ผุดขึ้นตรงกึ่งกลางฉากรับภาพ เครื่องมือนี้พิสูจน์ให้เห็นถึงพลังในการแยกแยะและการวัดละเอียดในระดับนาโนเมตร (High-Resolution Spectroscopy) ซึ่งเป็นไปตามสภาวะอุดมคติของสมการการแทรกสอดหลายลำรังสีอย่างถูกต้อง

8. วิจารณ์ผลการทดลอง

ในการทดลองผ่านระบบจำลองคอมพิวเตอร์เสมือนจริง ผลลัพธ์ที่ได้จะมีความแม่นยำสูงมากและมีเปอร์เซ็นต์ความคลาดเคลื่อนเข้าใกล้ 0% เนื่องจากระบบจำลองขึ้นภายใต้สภาวะอุดมคติทางคณิตศาสตร์ อย่างไรก็ตาม หากพิจารณาเปรียบเทียบกับการจัดตั้งอุปกรณ์ภายในห้องปฏิบัติการจริง จะมีปัจจัยภายนอกและข้อคลาดเคลื่อนสำคัญที่นักศึกษาต้องวิเคราะห์และพึงระวังดังต่อไปนี้:

  • ข้อคลาดเคลื่อนจากการนับด้วยสายตา (Human Visual Error): ในการทดลองจริง การนับจำนวนวงแหวนสว่าง N ที่ผุดขึ้นหรือยุบลงตรงกึ่งกลาง Crosshair อาจเกิดความสับสนหรือนับขาด/เกินได้ง่าย หากผู้ทดลองละสายตาหรือเลื่อนระยะกระจกเร็วเกินไป ซึ่งจะส่งผลให้ค่า N คลาดเคลื่อนไปเป็นจำนวนเต็ม และทำให้ค่า λcal ผิดเพี้ยนไปจากเดิมอย่างมาก
  • ความขนานของหน้ากระจกสะท้อน (Mirror Alignment): เครื่อง Fabry-Pérot ไวต่อการจัดวางหน้ากระจก M1 และ M2 มาก หากกระจกทั้งสองแผ่นไม่ได้ระนาบขนานกันอย่างสมบูรณ์ในระดับเศษเสี้ยวของความยาวคลื่น ริ้วรอยแทรกสอดวงแหวนจะไม่เป็นวงกลมที่สมบูรณ์ แต่จะบิดเบี้ยว เบลอ หรือกลายเป็นริ้วเส้นโค้งรูปพัด ส่งผลให้ไม่สามารถระบุจุดศูนย์กลางและนับวงแหวนได้อย่างชัดเจน
  • ผลกระทบจากการสั่นสะเทือนทางกลและอุณหภูมิ (Mechanical Vibration & Thermal Drift): เนื่องจากเรากำลังวัดระยะขยับในหน่วยระดับนาโนเมตร แรงสั่นสะเทือนเพียงเล็กน้อยจากการเดินในห้องปฏิบัติการ เสียง หรือการขยับโต๊ะทดลอง สามารถส่งผลให้ระยะ d คลาดเคลื่อนได้ รวมถึงการขยายตัวทางความร้อนของโครงสร้างยึดกระจกเมื่ออุณหภูมิห้องเปลี่ยนไป ก็ส่งผลต่อความนิ่งของริ้วแสงแทรกสอดเช่นกัน
  • อิทธิพลของค่าการสะท้อนแสง (R): จากการทดลองปรับค่า R จะเห็นว่าเมื่อค่า R ต่ำลง (เช่น 70%) แถบริ้วสว่างจะแผ่กว้างปนกับแถบมืด ทำให้ระบุจังหวะการผุดขึ้นของวงแหวนได้ยาก แต่เมื่อปรับค่า R สูงขึ้น (95%) เส้นริ้วสว่างจะแคบและคมชัดขึ้นอย่างชัดเจน ซึ่งช่วยลดความคลุมเครือในการสังเกตได้อย่างมีนัยสำคัญ
