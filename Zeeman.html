คู่มือการทำปฏิบัติการฟิสิกส์

เรื่อง: ปรากฏการณ์ซีมาน (Zeeman Effect)

1. ชื่อเรื่อง

การศึกษาปรากฏการณ์ซีมานปกติ (Normal Zeeman Effect) และการแยกออกของระดับพลังงานของอะตอมก๊าซภายใต้สนามแม่เหล็กภายนอกผ่านวงแหวนแทรกสอด

2. อุปกรณ์การทดลอง

  1. หลอดก๊าซเรืองแสงชนิดปล่อยประจุ (Gas Discharge Tube): สำหรับเป็นแหล่งกำเนิดแสง ประกอบด้วยสารตัวอย่าง ได้แก่ นีออน (Neon, λ = 585.2 nm), ปรอท (Mercury, λ = 546.1 nm) หรือ แคดเมียม (Cadmium, λ = 643.8 nm)
  2. แม่เหล็กไฟฟ้า (Electromagnet Poles): ชุดขั้วแม่เหล็ก N และ S สำหรับสร้างสนามแม่เหล็กสม่ำเสมอภายนอก (ภาระงานปรับได้ตั้งแต่ 0 ถึง 1.5 Tesla) เพื่อแยกแกนพลังงานของอะตอม
  3. เลนส์รวมแสงชิ้นที่ 1 (Collimating Lens - f1): สำหรับปรับลำแสงที่กระจายออกจากหลอดก๊าซให้เป็นลำแสงขนาน
  4. แผ่นกรองแสงระบุความยาวคลื่น (Interference Filter): สำหรับคัดเลือกเฉพาะความยาวคลื่นเดี่ยวที่ต้องการศึกษาของก๊าซแต่ละชนิด
  5. Fabry-Pérot Etalon: อุปกรณ์หัวใจหลักในการแยกวงแหวนแทรกสอด มีช่องอากาศหนา d (ปรับตั้งค่าได้ในช่วง 2.0 ถึง 6.0 mm)
  6. เลนส์กล้องโฟกัสภาพตัวที่ 2 (Imaging Lens - f): สำหรับสร้างวงแหวนภาพแทรกสอดปลายทาง มีความยาวโฟกัส f (ปรับตั้งค่าได้ในช่วง 150 ถึง 450 mm)
  7. ฉากรับภาพและกล้องบันทึกประมวลผล (CCD Sensor Camera): ควบคู่ระบบครอสแฮร์ (Crosshair) และสเกลไม้บรรทัดวัดรัศมีเพื่ออ่านค่าวงแหวนดิจิทัล

3. ทฤษฎี

ปรากฏการณ์ซีมาน (Zeeman Effect) คือปรากฏการณ์ที่เส้นสเปกตรัมของแสงแยกออกเป็นหลายเส้นเมื่อแหล่งกำเนิดแสงอยู่ภายใต้สนามแม่เหล็กภายนอก ซึ่งเกิดจากการที่สนามแม่เหล็กภายนอกไปอันตรกิริยากับโมเมนต์แม่เหล็กเชิงมุมของอิเล็กตรอน ทำให้อะตอมที่มีระดับพลังงานซ้ำซ้อนกัน (Degenerate States) เกิดการแยกตัวออกจากกันตามค่าควอนตัมแม่เหล็ก (mj หรือ ml)

ในกรณีของปรากฏการณ์ซีมานปกติ (Normal Zeeman Effect) ระดับพลังงานจะแยกออกเป็น 3 ระดับย่อยตามค่า Δm = 0, ±1 ทำให้สังเกตเห็นเส้นสเปกตรัมแยกออกเป็น 3 เส้น ค่าพลังงานที่แยกออก (ΔE) แปรผันตรงกับความเข้มสนามแม่เหล็กภายนอก (B) ตามสมการ:

ΔE = μB · B

โดยที่ μB คือค่าโบร์แมกเนตอน (Bohr Magneton) มีค่าคงที่เท่ากับ 5.788 × 10-5 eV/T

ในการวิเคราะห์ผลทางกายภาพผ่านชุด Fabry-Pérot Interferometer วงแหวนแทรกสอดที่เกิดขึ้นจะเกิดการแยกตัวออกเมื่อมีการจ่ายสนามแม่เหล็ก เราสามารถคำนวณหาพลังงานที่แยกออก (ΔE) จากการวัดขนาดของรัศมีวงแหวนแทรกสอดผ่านความสัมพันธ์ทางทัศนศาสตร์ดังนี้:

ΔE = (h · c / 4d) · ((R22 - R12) / f2)

คำอธิบายตัวแปร:

  • h (Planck constant) = 4.1357 × 10-15 eV·s
  • c (Speed of light) = 3 × 108 m/s
  • d = ความหนาของช่องอากาศภายใน Etalon (mm)
  • f = ความยาวโฟกัสของเลนส์วัตถุที่ใช้สร้างวงแหวนภาพแทรกสอด (mm)
  • R1 = รัศมีของวงแหวนแทรกสอดวงในที่แยกตัวออก (mm)
  • R2 = รัศมีของวงแหวนแทรกสอดวงนอกที่แยกตัวออก (mm)

4. วิธีการทดลอง

  1. เปิดเครื่องและเลือกชนิดของก๊าซในหลอดทดลองที่ต้องการศึกษา (เช่น Neon, Mercury หรือ Cadmium) จากแผงควบคุมระบบ
  2. ตั้งค่าคงที่ทางแสงเริ่มต้นของอุปกรณ์ ได้แก่ ความหนาของช่องอากาศ Etalon (d) และความยาวโฟกัสของเลนส์ (f) ให้เหมาะสม
  3. ตรวจสอบลักษณะวงแหวนหลัก (R0) บนหน้าจอ Optics Viewfinder ในขณะที่ยังไม่จ่ายสนามแม่เหล็ก (B = 0.00 Tesla) สังเกตว่าวงแหวนมีความคมชัดและเป็นเส้นเดี่ยว บันทึกค่ารัศมี R0
  4. เปิดสวิตช์จ่ายสนามแม่เหล็ก (<-- Magnet ON -->) จากนั้นปรับความเข้มสนามแม่เหล็ก (B) เพิ่มขึ้นทีละขั้น เช่น 0.50 T, 1.00 T, 1.50 T
  5. เมื่อจ่ายสนามแม่เหล็ก สังเกตการแยกออกของวงแหวนแทรกสอดเดี่ยวกลายเป็นวงคู่ (Split Rings) ให้ใช้เครื่องมือวัดบันทึกค่ารัศมีวงใน (R1) และรัศมีวงนอก (R2)
  6. กดปุ่ม "บันทึกผล" เพื่อนำข้อมูลลงตารางบันทึกผลการทดลอง และทำการทดลองซ้ำโดยเปลี่ยนค่าสนามแม่เหล็ก B หรือเปลี่ยนชนิดของก๊าซเพื่อเปรียบเทียบผล

6. ผลการทดลองและการคำนวณ

จากผลการทำปฏิบัติการจำลอง พบว่าเมื่อความเข้มสนามแม่เหล็ก B มีค่าเป็นศูนย์ เส้นสเปกตรัมหรือวงแหวนแทรกสอดที่ปรากฏบนกล้องส่องจะมีลักษณะเป็นเส้นเดี่ยวคมชัด (R0 = 1.13 mm) แต่เมื่อเปิดจ่ายสนามแม่เหล็กภายนอกและเพิ่มความเข้มขึ้น วงแหวนหลักจะแยกออกเป็นสองวงอย่างเห็นได้ชัด โดยระยะห่างระหว่างวงในและวงนอก (ΔR = R2 - R1) จะกว้างขึ้นเรื่อยๆ ตามความเข้มสนามแม่เหล็กที่เพิ่มขึ้น

เมื่อนำค่ารัศมี R1 และ R2 ที่วัดได้มาคำนวณหาค่าพลังงานที่แยกออก (ΔE) พบว่าที่สนามแม่เหล็ก 0.50 T ได้ค่า ΔE ≈ 0.29 × 10-4 eV และเพิ่มขึ้นเป็น 0.58 × 10-4 eV ที่สนามแม่เหล็ก 1.00 T ซึ่งผลการคำนวณจากสูตรทัศนศาสตร์สอดคล้องอย่างแม่นยำกับค่าทางทฤษฎีของซีมาน ΔE = μB · B

7. สรุปผลการทดลอง

การทดลองนี้ประสบความสำเร็จในการพิสูจน์และศึกษาปรากฏการณ์ซีมานปกติ (Normal Zeeman Effect) โดยผลการทดลองแสดงให้เห็นอย่างชัดเจนว่า สนามแม่เหล็กภายนอกส่งผลให้ระดับพลังงานของอะตอมเกิดการแยกตัวออกจากกัน ซึ่งสะท้อนออกมาในรูปแบบของการแยกออกของวงแหวนแทรกสอด Fabry-Pérot ความสัมพันธ์ระหว่างพลังงานที่แยกออก (ΔE) และความเข้มสนามแม่เหล็ก (B) มีความสัมพันธ์เชิงเส้นแปรผันตรงต่อกันอย่างถูกต้องตามทฤษฎีควอนตัมของอะตอม

8. วิจารณ์ผลการทดลอง

จากการทดลองจำลอง ระบบมีความแม่นยำสูงเนื่องจากเป็นสภาวะอุดมคติ อย่างไรก็ตาม ในการทดลองจริงอาจมีข้อคลาดเคลื่อนที่ต้องระวังหลายประการ ดังนี้:

  • ความละเอียดในการวัดด้วยสายตาหรือ CCD: การระบุจุดกึ่งกลางและความกว้างของวงแหวนแทรกสอดอาจมีความคลาดเคลื่อน (Human Error / Pixel Resolution) ซึ่งการใช้ระบบประมวลผลภาพดิจิทัล (Crosshair) ในห้องปฏิบัติการเสมือนนี้ช่วยลดปัญหานี้ลงได้มาก
  • คุณภาพของ Fabry-Pérot Etalon: หากระนาบกระจกสะท้อนคู่ขนานภายในห้องอากาศไม่มีความขนานกันอย่างสมบูรณ์ จะส่งผลให้วงแหวนแทรกสอดบิดเบี้ยวและเบลอ ทำให้ความแม่นยำในการวัดลดลง
  • ความสม่ำเสมอของสนามแม่เหล็ก: สนามแม่เหล็กระหว่างขั้ว Pole N และ S ต้องมีความสม่ำเสมอตรงตำแหน่งของหลอดแก้วก๊าซ หากเกิดการกระจัดเชิงตำแหน่ง ค่า B ที่แท้จริงอาจไม่เท่ากับค่าที่ตั้งไว้จากตัวควบคุม
